# 象棋真人玩家模块

更新时间：2026-05-23

象棋真人玩家模块是具体游戏真人玩家实现，负责把象棋房间模块发出的走棋、求和、悔棋、认输和聊天请求转换成人能操作的 UI 输入，再把真人输入包装成统一象棋行动结果。

## 模块定位

```text
玩家模块
  -> 真人玩家模块
       -> 象棋真人玩家模块
            -> 棋子选择 / 目标格选择
            -> 求和 / 悔棋 / 认输确认
            -> 聊天输入
            -> XiangqiPlayerActionResult
```

象棋真人玩家模块只处理“人如何提交一次象棋响应”。最终走法是否合法、是否将军、是否胜负和是否推进回合，仍由象棋房间模块裁决。

## 能力边界

象棋真人玩家模块负责：

- 接收 `XiangqiActionRequest`。
- 打开走棋交互，支持点击选择棋子和目标格。
- 显示当前可操作方、最近一步、将军提示和可用操作。
- 处理认输、求和、悔棋确认。
- 处理公开聊天输入。
- 把真人输入转换为 `XiangqiPlayerActionResult`。
- 通过玩家模块可信通道提交给主机。
- 断线重连后恢复当前待处理请求和本机 UI 状态。

象棋真人玩家模块不负责：

- 棋子走法最终校验。
- 胜负、和棋、超时和棋谱权威写入。
- 房间加入、换座、机器人加入和网络同步。
- AI 行棋、AI 聊天、prompt 和模型调用。

## UI 交互

走棋：

- 只在轮到本方时允许选择己方棋子。
- 选择棋子后高亮候选目标格；候选目标可由本地预估，但只作为辅助。
- 再次点击已选棋子取消选择。
- 点击目标格后提交结构化起点和终点。
- 主机拒绝后，清除本次提交态并展示错误提示。

聊天：

- 真人玩家可以公开发言。
- 聊天提交后进入房间聊天事件，不影响当前走棋请求。
- 真人发言可以触发 AI 聊天回应，但不触发 AI 额外走棋。

求和、悔棋、认输：

- 认输需要二次确认。
- 求和和悔棋发送给对手响应。
- 收到对手求和或悔棋时，必须显式同意或拒绝。
- 弹窗不支持点击空白关闭，必须处理后关闭。

## 维护规则

- 真人 UI 不能直接修改棋盘。
- 未经主机接受的走棋和聊天草稿不能进入历史、TTS 或复盘。
- UI 里的合法走法提示不能替代象棋房间模块校验。
- 所有提交都使用权威坐标，不使用旋转后的屏幕坐标。
