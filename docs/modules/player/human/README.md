# 真人玩家模块

更新时间：2026-05-21

真人玩家模块是玩家模块的子模块，负责所有由人操作的玩家控制器能力。它不理解具体游戏规则，只负责接收通用 `PlayerActionRequest`，打开本机或远程真人交互入口，并把人的输入转换成统一 `PlayerActionResult`。

## 模块定位

```text
玩家模块
  -> 真人玩家模块
       -> 本机真人控制器
       -> 远程真人控制器
       -> 真人玩家请求投递和输入回收
       -> 断联恢复后的真人请求重投递
  -> 具体游戏真人玩家模块
       -> 狼人杀真人玩家模块
       -> 象棋真人玩家模块
```

真人玩家模块只处理“人如何完成一次玩家请求”。具体游戏的按钮、目标列表、文本输入和提示文案由具体游戏真人玩家模块提供。

## 能力边界

真人玩家模块负责：

- 区分本机真人、远程真人和旁路托管入口。
- 接收通用玩家行为请求。
- 通过玩家级可信通道投递请求、接收 ACK 和结果。
- 管理真人玩家待处理请求、超时、取消和断联恢复重投递。
- 把真人输入包装成统一 `PlayerActionResult`。
- 提供具体游戏真人玩家模块可复用的请求状态和通用结果 payload 包装能力。

真人玩家模块不负责：

- 具体游戏规则、行动合法性、阶段推进和胜负判断。
- 狼人杀身份、目标合法性、发言顺序和警长流程。
- AI prompt、模型调用、机器人记忆和模型输出解析。
- TTS 引擎实现和声音配置存储。

## 代码归属

```text
scripts/player/human/
  human_player_controller.gd
```

具体游戏真人玩家实现放在对应游戏目录，例如狼人杀真人玩家模块位于 `scripts/player/werewolf/human/`，象棋真人玩家模块位于 `scripts/player/xiangqi/human/`。
