# 警长广场

更新时间：2026-05-22

`sheriff_square` 使用 `警长广场规则` 地图规则配置。它按人数配置预言家、女巫、猎人和白痴，并启用警长竞选、警长投票、警长决定白天发言顺序、警长死亡后的警徽处理和警长票权。

## 简单描述

警长地图，增加警长竞选、警长投票、警长决定白天发言顺序、警徽处理和警长票权。地图强化开局发言、拉票、站边、发言顺序安排、警徽归属和白天票型推理。

## 详细规则

- 开局先进入警长竞选发言。
- 警长投票完成后产生警长，再进入第一夜。
- 夜晚结算、放逐或猎人开枪导致当前警长死亡时，先进入警徽处理。
- 死亡警长可以飞警徽给一名存活玩家；该玩家成为新警长，继承警长票权和后续白天发言顺序决定权。
- 死亡警长也可以撕警徽；撕毁后本局不再有警长、警长票权或警长指定发言顺序。
- 处理完警徽、遗言和猎人流程后，如果警长仍存活，先由警长决定白天发言顺序。
- 警长发言顺序行动需要指定一名存活玩家作为首发言位，并选择顺时针或逆时针；首发言位可以是警长本人。
- 没有存活警长或警长无法决定时，白天按座位顺序发言。
- 放逐投票结算时警长票权按地图策略计入票型。
- 白痴存在的人数下，白痴被白天放逐时翻牌免于出局，之后失去投票权。
- 本地图采用屠边规则：狼人全部出局则好人胜利；村民全部出局或神职全部出局则狼人胜利。
- 其它夜晚推理按当前人数身份配置执行。

## 下发策略

- 警长竞选发言和警长投票结果公开。
- 警长身份、飞警徽和撕警徽结果公开展示。
- 夜晚私有结果仍按身份下发，不因警长存在而扩大范围。
- 票型公开时可以公开警长票权影响，但不能暴露投票阶段前未公开的身份。

## 推理上下文摘要

给玩家适配层的当前玩家输入摘要应强调：

- 本地图存在警长竞选、警徽处理、警长发言顺序和警长票权，发言与投票会影响后续放逐。
- 每天白天发言前，存活警长可以指定从某号位开始并按顺时针或逆时针发言；这会影响玩家听信息、归票和站边的节奏。
- 当前警长死亡时要判断飞警徽或撕警徽对票权、归票和发言顺序的影响。
- 白痴翻牌会改变放逐收益和后续投票权，但不会直接造成死亡。
- AI 机器人玩家在警长竞选阶段应围绕身份立场、可信度和拉票目标发言。
- 放逐阶段需要把警长票权作为公开规则纳入推理。
