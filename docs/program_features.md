# 程序功能

更新时间：2026-05-21

本文从使用者视角列出 Play With Me 当前已经提供的软件功能。

## 大厅

- 横屏游戏大厅界面。
- 房间卡片展示游戏房间、地图、人数、密码状态和地址。
- 支持本机房间、局域网发现房间和上次可重连房间。
- 工具栏入口包括刷新房间、创建房间、扫描加入、模型配置、机器人配置、声音配置和偏好设置。

## 创建房间

- 创建 UI 从可创建目录读取玩法、地图和支持人数。
- 当前玩法：狼人杀。
- 当前狼人杀基础地图支持 6、7、8、9 个席位；警长广场支持 10、12 个席位；警长守卫广场支持 12 个席位。
- 支持设置房间密码。
- 支持选择狼人杀地图：
  - 标准预女猎。
  - 猎人压力局。
  - 无女巫快节奏。
  - 守卫标准局。
  - 警长预女猎白。
  - 警长守卫预女猎守。
- 创建后自动进入房间桌面，并启动本机房主网络。

## 偏好设置

- 支持从大厅进入偏好设置。
- 用于管理本机昵称、内置头像、播放声音配置和设备私钥查看。
- 首次启动如果本机偏好 JSON 不存在，会自动生成昵称、头像、播放声音配置引用和设备私钥。
- 昵称、头像和播放声音配置可以修改；头像只能从 24 个默认头像中选择，不支持上传。
- 设备私钥自动生成，只能查看，不能修改。
- 偏好不保存模型配置详情、声音配置详情、机器人配置、基础认证判断或房间权威状态。

## 房间桌面

- 椭圆桌面布局。
- 圆形座位卡展示头像、身份、名字、状态和动效。
- 空座位支持落座、切换座位和添加机器人。
- 已占座位支持查看详情。
- 本人支持改名；机器人玩家名称来自机器人档案，不在房间内修改。
- 支持准备/取消准备。
- 支持二维码面板，复制玩家加入码和观战码。
- 支持右侧历史面板。
- 对局结束后支持进入复盘页。

## 狼人杀房间模块

- 支持身份发放。
- 支持狼人夜晚袭击。
- 支持守卫守护，且不能连续守护同一名玩家。
- 支持预言家查验。
- 支持女巫救人和毒人。
- 支持白天顺序发言。
- 支持放逐投票。
- 支持警长竞选、警长发言顺序、警徽票权，以及警长死亡后的飞警徽/撕警徽。
- 支持遗言。
- 支持猎人开枪。
- 支持好人/狼人胜负判断。
- 支持赛后总结和 MVP 投票。

## AI 机器人

- 房主或参与者可在空位添加机器人。
- 机器人可绑定机器人档案、模型和声音配置。
- 机器人可自动执行夜晚行动、投票、发言、赛后总结和 MVP 投票。
- 模型不可用、请求超时或输出不合法时，机器人返回错误并中止当前游戏流程，不生成兜底行动。
- 狼人机器人支持夜聊和目标票。

## 模型配置

- 支持新增、编辑和删除模型配置。
- 支持供应商：
  - Ollama。
  - OpenAI API 格式。
  - Anthropic。
  - Gemini。
- 支持配置模型名、Endpoint、API Key、MaxContext、MaxOutput、Temperature 和 Reasoning。
- `MaxContext` 界面直接填写 token 数，不显示单位；默认 `262144`，运行时上下文预算 `context_window_tokens = max_context * 0.7`。
- `MaxOutput` 表示最大输出 token，单个新增和编辑界面可设置，默认 `4096`；批量新增不展示该字段。
- 支持从供应商接口获取模型，单个弹层可填入模型名，批量新增弹层可勾选多个模型后一次添加。
- Android 真机优先使用 SQLite 保存模型配置；桌面/编辑器使用本地 JSON 保存。

## 声音配置

- 支持系统 TTS、Kokoro、NekoTTS、VoxSherpa-TTS 和 MultiTTS。
- Android 真机支持系统 TTS 音色列表。
- Android 真机支持本地 Kokoro/Sherpa 音色和应用内非系统 TTS 引擎音色。
- 支持语速、音调、音量、启用状态和主用声音配置。
- 支持在配置页试听，并展示试听文本和播放进度。
- 房间历史消息可按偏好设置中选择的声音配置播报。
- 详细规则见 `docs/modules/tts-voice/voice_config.md`。

## 机器人配置

- 支持查询机器人列表。
- 支持添加、编辑和删除机器人档案。
- 机器人档案保存名称、描述、人设、默认模型、默认声音、启用状态和综合记忆。
- 记忆属于机器人档案本身，不作为单独命名配置对外暴露。
- 人设可空；为空时机器人只根据自身记忆自进化，填写后作为初始人格模板并随记忆继续演化。
- 支持从机器人配置页进入独立机器人记忆页，查看人设快照、工作记忆、关系记忆、事件记忆、语义记忆、反思记忆、检索状态、维护状态和索引状态；完整记忆视图不使用弹窗，页面默认只读，不直接保存。
- 机器人对局过程会写入会话记忆。
- 对局结束后会生成长期记忆摘要。
- 机器人档案随应用状态保存；运行时记忆桌面侧使用本地 JSON，Android 真机优先使用 SQLite。
- 支持按当前回合检索相关记忆，帮助机器人保持上下文一致。

## 局域网和联机

- 房主通过 WebSocket 维护房间。
- 大厅通过 UDP 发现局域网房间。
- 支持扫码加入和粘贴加入码。
- 支持参与者加入、落座、准备、改名、添加机器人、行动和发言请求。
- 支持观战码，观察者以只读方式查看房间。
- 支持断线重连。
- 支持房主断线后的自动接管。

## 复盘

- 展示本局结果。
- 展示地图和人数。
- 展示最终身份、存活/死亡状态和 MVP。
- 展示关键时间线。

## Android 能力

- 相机扫码加入房间。
- 系统 TTS 播放。
- 本地 Kokoro/Sherpa 播放。
- SQLite 记忆存储。
- SQLite 模型配置存储。
- Android 设备身份能力。
- Gradle Android 导出。
